# Outils Facilitime — les versions

Ce dépôt ne contient que les versions de l'application Outils Facilitime, pas
son code.

## La première installation

1. Ouvrir la dernière version : https://github.com/Fugipe/outils-facilitime-versions/releases/latest
2. Télécharger l'archive « Outils-Facilitime-….zip », puis l'ouvrir.
3. Glisser « Outils Facilitime » dans le dossier Applications.
4. À sa première ouverture, macOS demande de le confirmer : Réglages ›
   Confidentialité et sécurité › « Ouvrir quand même ».

## Les versions suivantes

L'outil les trouve lui-même. Le bouton vert « Version … disponible » de son
accueil montre ce qui change, et « Installer » télécharge la nouvelle version,
vérifie qu'elle est bien signée, remplace l'outil et le rouvre. Plus rien à
confirmer.
